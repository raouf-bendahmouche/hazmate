## Module 1: System Basics

### 1.1 Understanding the System

#### What is the License Management System?

The License Management System is a specialized application designed to:

- Digitally record hazardous material transport operations
- Track driver and vehicle licenses
- Monitor license expiration dates
- Ensure regulatory compliance
- Generate compliance reports

#### Why Do We Use It?

- **Efficiency** - Replace manual record keeping with digital records
- **Accuracy** - Reduce data entry errors
- **Compliance** - Meet government regulations
- **Reporting** - Generate instant statistical reports
- **Security** - Ensure data is backed up and protected

### 1.2 System Overview

#### Main Components

1. **Dashboard** - Home page with key statistics
2. **Data Entry** - Form to add new transport records
3. **Search** - Find and manage existing records
4. **Statistics** - View charts and reports
5. **Settings** - Configure system preferences

#### Key Concepts

**License** - Official permission for a driver to transport hazardous materials

- Has an expiration date
- Status: Active or Expired
- Tied to specific vehicle and driver

**Company** - Transportation company or carrier

- Has unique registration number
- Associated with multiple vehicles
- Tracked by carrier type

**Vehicle** - Transport vehicle (truck, tanker, van)

- Registered with company
- Has specific category and type
- Can carry hazardous materials

**Record** - Single transport operation instance

- Contains all parties involved (company, driver, vehicle)
- Route from origin to destination
- Signature date (when transport occurred)

**Hazardous Material** - Dangerous goods being transported

- Material type identified
- Special handling noted

## Module 2: Data Entry Training

### 2.1 Data Entry Overview

#### Why Accurate Data Entry Matters

- **Compliance** - Regulatory requirements
- **Accuracy** - Prevents errors in reports
- **Efficiency** - Saves time with correct first-entry
- **Traceability** - Maintains audit trail

#### Data Entry Checklist

Before starting data entry:

- ✓ All required information available
- ✓ Document clearly readable
- ✓ Contact person available for questions
- ✓ Enough time to complete accurately

### 2.2 Step-by-Step Data Entry

#### Opening Data Entry Form

1. Click "Add New Record" button on dashboard
2. Data Entry window opens
3. Form shows multiple sections to fill

#### Section 1: Company Information

**Required Fields:**

- **Company Name** - Full legal name of company
  - If new company, type name and press Tab
  - If existing, select from dropdown
  - Example: "National Transport Ltd"

- **Registration Number** - Official company registration ID
  - Usually displayed on company letterhead
  - Example: "REG-2024-12345"

- **Address** - Company headquarters address
  - Include street, city, postal code
  - Example: "123 Main Street, Cairo, 11111"

- **Carrier Type** - Category of transportation company
  - Select from dropdown (International, Domestic, etc.)
  - Affects compliance requirements

- **Account Type** - Type of business arrangement
  - Options: Supplier, Contractor, Partner, etc.

**Data Entry Tips:**

- Use consistent spelling for company names
- Keep addresses complete for legal purposes
- Verify registration numbers with company documents
- Select carrier type from options (don't type new values)

#### Section 2: Vehicle Information

**Required Fields:**

- **Vehicle Registration** - License plate number
  - Unique identifier for vehicle
  - Example: "EG-ABC-12345"
  - MUST be unique (system will warn if duplicate)

- **Vehicle Type** - Category of vehicle
  - Options: Truck, Van, Tanker, Flatbed, etc.
  - Select from dropdown

- **Vehicle Category** - Classification level
  - Options: Rigid, Articulated, Semi-trailer, etc.
  - Important for routing and compliance

**Data Entry Tips:**

- Vehicle registration must be EXACTLY as on vehicle documentation
- Double-check for typos in registration number
- Select vehicle type based on cargo capacity
- Confirm category matches actual vehicle configuration

#### Section 3: Route Information

**Required Fields:**

- **Origin City** - Starting location of transport
  - Where goods loaded onto vehicle
  - Example: "Alexandria"

- **Destination City** - Final destination
  - Where goods unloaded
  - Example: "Cairo"

- **Checkpoints** (Optional) - Important stops or waypoints
  - Intermediate stops for inspection or rest
  - Separate multiple entries with commas
  - Example: "Giza Checkpoint, Benha Station"

**Data Entry Tips:**

- Use consistent city names for all entries
- Checkpoints optional but recommended for hazmat
- List checkpoints in order of travel
- Include inspection points and permitted rest stops

#### Section 4: License & Driver Information

**Required Fields:**

- **Record Number** - Unique identifier for this transport record
  - System generates if left blank, or provide own
  - Example: "TRANS-2026-001234"
  - MUST be unique in system

- **Driver Name** - Full name of transport driver
  - First and last name required
  - Example: "Ahmed Hassan Mohammed"
  - Name must match license document

- **Driver Phone** - Contact number for driver
  - Include area code
  - For emergency contact purposes
  - Example: "+20-123-4567890"

- **License Number** - Hazmat transport license number
  - From official license document
  - MUST be unique in system
  - Example: "HZM-2024-987654"

- **Signature Date** - When the record was authorized
  - Date driver or manager signed the record
  - Format: YYYY-MM-DD
  - Example: "2026-04-11"

- **Expiration Date** - When driver license expires
  - CRITICAL for compliance monitoring
  - Format: YYYY-MM-DD
  - Example: "2027-04-11"
  - System automatically calculates status based on this date

**Data Entry Tips:**

- Record number should follow company's naming convention
- Driver name MUST match exactly on license document
- Always get phone number - required for notifications
- Use official license number from document
- Dates critical - verify twice, system highlights near-expiration
- Status auto-calculates - active if today < expiration_date

#### Section 5: Hazardous Materials (If Applicable)

**Required Fields (when transporting hazmat):**

- **Material Type** - Classification of hazardous material
  - From hazmat documentation
  - Example: "Class 3 - Flammable Liquid"

**Data Entry Tips:**

- Only fill if transporting hazardous materials
- Be precise with material classification
- Keep MSDS documentation available
- Multiple materials? Can add multiple entries

### 2.3 Saving Records

#### Before Clicking Save

- Review all fields for accuracy
- Verify dates are correct
- Check spelling of names and companies
- Confirm vehicle and license numbers unique
- Verify all required fields (marked with \*) completed

#### Saving Process

1. Click "Save Record" button (usually bottom right)
2. System validates data:
   - Checks for required fields
   - Verifies unique values (registration, license number)
   - Validates date format (YYYY-MM-DD)
   - Checks date logic (expiration after signature)
3. Confirmation message appears if successful
4. Record added to database
5. Form clears for next entry

#### If Errors Occur

**Common Errors & Solutions:**

| Error                          | Cause                         | Solution                          |
| ------------------------------ | ----------------------------- | --------------------------------- |
| "Record number already exists" | Duplicate record ID           | Use different/unique number       |
| "License number required"      | Missing field                 | Fill license field before saving  |
| "Invalid date format"          | Date not YYYY-MM-DD           | Use correct format: 2026-04-11    |
| "Company not found"            | Company doesn't exist         | Add company first with all fields |
| "Vehicle registration in use"  | Registration number duplicate | Verify with existing records      |

#### After Saving

- Confirmation message displays: "Record saved successfully"
- New record appears in database immediately
- Can view in Search Records window
- Automatically included in statistics

### 2.4 Quality Assurance

#### Double-Checking Data Entry

1. **Before Saving:**
   - Read each field aloud
   - Compare to source document
   - Check dates twice (especially expiration)
   - Verify unique fields (registration, license number)

2. **Best Practices:**
   - Enter one record at a time without distractions
   - Take 30-second break after every 5 records
   - Have companion verify entries periodically
   - Check name spellings in company documents

3. **Common Entry Mistakes:**
   - Transposing numbers in registration plate
   - Date format errors (DD/MM vs MM/DD confusion)
   - Missing area codes in phone numbers
   - Gender-specific name variations (Ahmed vs Ahmed)
   - Space/punctuation inconsistencies

#### Verification Checklist

Before saving each record:

- [ ] Company name spelled correctly
- [ ] Vehicle registration matches documentation
- [ ] Driver name matches license exactly
- [ ] License number from official document
- [ ] Dates in YYYY-MM-DD format
- [ ] Expiration date makes sense (future date)
- [ ] Phone number includes area code
- [ ] All required fields completed
- [ ] No obvious typos or errors

## Module 3: Search & Retrieval

### 3.1 Opening Search Interface

**Steps:**

1. From main dashboard, click "Search Records"
2. Search window opens showing records list
3. Empty search returns all records (up to 100 per page)

### 3.2 Basic Search

#### Searching by Text

1. Click in search field at top of window
2. Type search term (partial match acceptable):
   - Record number: "TRANS-001"
   - Vehicle registration: "EG-ABC"
   - Company name: "National"
   - Driver name: "Ahmed"
3. Results update as you type
4. Click "Search" button to confirm search

#### Search Tips

- Don't need exact full text
- Search is case-insensitive (lowercase/UPPERCASE same)
- Partial matches work: "Cairo" finds "Cairo Transport Ltd"
- Fastest search: record number or vehicle registration
- Leave blank to see all records

### 3.3 Advanced Filtering

#### Status Filter

Filter to view only specific license statuses:

- **Active** - Licenses not yet expired
- **Expired** - Licenses past expiration date
- Both - View all records

**Why Filter by Status:**

- Find expiring soon for renewal planning
- Identify compliance issues
- Check driver qualification status

#### Carrier Type Filter

Filter by transportation company type:

- Shows records from specific carrier types
- Analyze by business category
- Compliance reporting

**Using Filters:**

1. Select status from Status dropdown (Active, Expired, or All)
2. Select carrier type from Carrier Type dropdown
3. Results automatically update
4. Combine with text search for most specific results

### 3.4 Working with Search Results

#### Understanding Result Columns

| Column          | Meaning                      | Example          |
| --------------- | ---------------------------- | ---------------- |
| Record Number   | Unique ID for this transport | TRANS-001234     |
| Vehicle Reg     | License plate                | EG-ABC-12345     |
| Company Name    | Transportation company       | Ahmed & Sons Ltd |
| Carrier Type    | Company category             | International    |
| Driver Name     | Transport driver             | Hassan Mohammed  |
| Signature Date  | When license was signed      | 2026-03-15       |
| Expiration Date | When license expires         | 2027-03-15       |
| Status          | Current license status       | Active / Expired |

#### Sorting Results

1. Click column header to sort by that column
2. Click again to reverse sort (A-Z or Z-A)
3. Most useful to sort by:
   - Expiration Date (find soon-to-expire)
   - Status (group active/expired)
   - Company Name (organize by carrier)

### 3.5 Record Actions

#### Viewing Full Details

1. Click on any record row to select it
2. Record details appear below
3. Review all information:
   - Company details
   - Vehicle information
   - Route details
   - Driver information
   - License expiration
   - Hazmat details (if any)

#### Editing Records

1. Select record from search results
2. Click "Edit" button
3. Edit window opens with current data
4. Modify fields as needed
5. Click "Save Changes"
6. Record updated immediately

**What Can Be Edited:**

- All company information
- Route details
- Driver information
- Expiration dates
- Status (if needed)

**What Cannot Be Edited:**

- Record number (unique identifier)
- License number (unique identifier)
- Vehicle registration (created with the record)

#### Deleting Records

1. Select record to delete
2. Click "Delete" button
3. Confirmation dialog appears:
   - "Are you sure you want to delete this record?"
   - "This action cannot be undone"
4. Click "Yes" to confirm deletion
5. Record permanently removed

**Important:**

- Deletion is PERMANENT
- Cannot be undone through undo function
- System should have current backups
- Use with extreme caution

#### Exporting Records

1. Perform search to get desired records
2. Click "Export" button
3. Choose export format:
   - CSV (spreadsheet compatible)
   - Excel (Microsoft Office format)
4. Choose save location
5. File saved with name: `export_YYYYMMDD_HHMMSS.csv`

## Module 4: Records Management

### 4.1 License Expiration Management

#### Understanding License Status

**Active License:**

- Expiration date is today or in the future
- Driver qualified to transport hazmat
- Can be used for new transport records
- Green indicator in system

**Expired License:**

- Expiration date is in the past
- Driver NOT qualified to transport hazmat
- Cannot be used for new transports
- Red indicator in system
- Requires renewal

#### Monitoring Expiring Licenses

**Dashboard Indicator:**

- Dashboard shows "Licenses Expiring in 30 Days"
- Count of licenses expiring within next 30 days
- Click to see which drivers need renewal

**Search Method:**

1. Open Search Records
2. Look for records with expiration dates within 30 days
3. Sort by expiration date (earliest first)
4. Identify drivers who need renewal

**Regular Monitoring:**

- Check expiring licenses weekly
- Contact companies 60 days before expiration
- Send renewal reminders 30 days before
- Track renewals in system

### 4.2 License Renewal Process

#### Before Renewal

1. Identify expiring license in system
2. Contact company/driver
3. Request new license documentation
4. Verify new license details

#### Recording Renewal

1. Edit existing record
2. Update expiration date with new date from license
3. Update status if changed
4. Add any notes about renewal
5. Save changes

#### Post-Renewal

1. Verify status shows as "Active"
2. Check renewed license shows correctly
3. Document renewal date for records
4. Update company files

### 4.3 Handling Multiple Records

#### Bulk Operations

**Updating Multiple Records:**

1. Search for records to update (e.g., by company)
2. Edit each individually (then save)
3. Or use Settings to batch update if available

**Merging Records:**

- If duplicate records created
- Cannot auto-merge
- Manual process: delete duplicate, keep original
- Verify records before deletion

#### Record Organization

**Naming Conventions:**

- Use consistent record naming: "TRANS-YYYY-NNNNN"
- Year and sequential number
- Makes sorting and searching easier

**Archiving Old Records:**

- Keep all records indefinitely for compliance
- Don't delete - use status as archive indicator
- Search filters can hide old records
- Periodic exports for long-term storage

## Module 5: Compliance & Reporting

### 5.1 Understanding Compliance Requirements

#### Regulatory Framework

Transportation of hazardous materials requires:

- Valid licenses for all drivers
- Current documentation
- Regular record keeping
- Compliance reporting
- Incident documentation

#### Our Compliance Approach

1. **Record Everything** - Each transport documented
2. **Monitor Expiration** - Track all license dates
3. **Status Tracking** - Know which licenses active/expired
4. **Regular Reports** - Generate compliance documentation
5. **Data Backup** - Protect records

### 5.2 Statistics Window

#### Accessing Statistics

1. Click "Statistics" from main dashboard
2. Statistics window opens with two tabs

#### License Statistics Tab

Shows three charts:

**Chart 1: Licenses by Status (Pie Chart)**

- Green slice = Active licenses
- Red slice = Expired licenses
- Percentage and count shown
- **Interpretation:** Should be large green slice (high active %)

**Chart 2: Licenses by Carrier Type (Pie Chart)**

- Shows distribution across company types
- Each type shown with percentage
- **Interpretation:** Identifies major transporters

**Chart 3: Top 10 Companies Bar Chart**

- Companies ranked by license count
- Blue bars show volume
- Highest on left to lowest on right
- **Uses:** Identify major clients/partners

**Expiring Soon Alert**

- Count of licenses expiring within 30 days
- **Action Required:** Plan renewals

#### Transport Statistics Tab

Shows three charts:

**Chart 1: Daily Transports (Line Chart)**

- Green line shows daily activity
- Covers last 30 days
- Peaks and valleys visible
- **Interpretation:** Operational patterns

**Chart 2: Weekly Transports (Bar Chart)**

- Blue bars for each week
- Shows last 12 weeks
- **Interpretation:** Weekly trends, volume forecasting

**Chart 3: Monthly Transports (Bar Chart)**

- Purple bars for each month
- Shows last 12 months
- **Interpretation:** Seasonal patterns, annual planning

### 5.3 Report Generation

#### Using Statistics for Reports

**Compliance Report:**

1. Open Statistics window
2. Screenshot or note key numbers
3. Create report template with:
   - Report date
   - Total active licenses
   - Total expired licenses
   - Percentage compliance (active/total)
   - List of expired licenses requiring action

**Activity Report:**

1. Open Transport Statistics tab
2. Review monthly data
3. Note total transports for period
4. Include trends and forecasts
5. Identify peak and low activity periods

**Audit Preparation:**

1. Generate all statistics reports
2. Export search results
3. Prepare license expiration list
4. Document any issues/exceptions
5. Archive all reports

#### Interpreting Statistics

**What Good Statistics Look Like:**

- High percentage active licenses (> 90%)
- Consistent or growing transport volume
- Clear patterns in weekly/monthly data
- No unexpected spikes or drops

**Red Flags:**

- High expired license percentage > 5%
- Sudden drop in transport activity
- Gaps in data or missing records
- Records with unclear or invalid information

### 5.4 Document Management

#### Important Documents to Keep

1. **License Documents** - Original copies stored
2. **Company Registrations** - Current documentation
3. **Backup Files** - Regular database backups
4. **Compliance Reports** - Monthly/quarterly reports
5. **Audit Trails** - Log of changes and deletions

#### Document Retention

- **Minimum Period** - 5+ years recommended
- **Digital Storage** - Multiple backups
- **Physical Copies** - Scanned and stored
- **Access Control** - Restricted to authorized staff

#### Report Archiving

1. Generate reports monthly
2. Save with clear naming: `Report_2026_April.pdf`
3. Store in secure folder: `Reports/Compliance/`
4. Backup to external drive
5. Verify backup integrity monthly

## April 2026 Training Addendum (Required for all staff)

### A) Deleted Contracts Workflow

- **What changed:** New **Deleted Contracts** page separates deleted contracts from active records.
- **Why changed:** Prevent accidental operations on archived data.
- **How it works:** Search + filter deleted contracts, then restore when needed.
- **Operator steps:**
  1. Open Deleted Contracts from sidebar.
  2. Search by ID/company/driver/vehicle.
  3. Filter by municipality/type/status-before-delete.
  4. Use **Restore Contract** to move record back to active lists.

### B) Quantity Field Removal

- **What changed:** Quantity is no longer entered or reviewed.
- **Why changed:** Quantity is out of current authority reporting scope.
- **How it works:** Hazardous material section only tracks material type.
- **Operator behavior:** Do not request quantity from data source when entering contracts.

### C) Menu Label Standardization

- **What changed:** Creation menu is now **Add Contract** in all languages.
- **Why changed:** Align wording with contract-oriented workflow.
- **How it works:** Label auto-translates when language changes.
- **Operator behavior:** Use Add Contract for all new contract entries.
